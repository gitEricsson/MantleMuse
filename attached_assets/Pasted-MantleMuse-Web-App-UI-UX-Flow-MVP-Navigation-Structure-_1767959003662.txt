MantleMuse Web App UI/UX Flow (MVP)
Navigation Structure
Top Nav (desktop)
Logo (MantleMuse)
Explore
Portfolio
How it Works
Connect Wallet / Wallet Chip (connected state)
Mobile
Hamburger: Explore, Portfolio, How it Works, Settings
Sticky bottom CTA on invest-related screens: “Invest” / “Confirm.”
Global UI Rules (for consistency)
No crypto jargon in primary UI.


Use “Invest”, “Shares”, “Payouts”, “Sell”, “Wallet” (ok), avoid “mint”, “token”, “gas”.


Always show 3 things clearly:


How money is made


What the risks are


How to exit


Every transaction has: Review → Confirm → Processing → Success/Fail states.


Every screen has a “What is this?” tooltip for finance terms (yield, royalties, appreciation).

Use Payouts instead of distributions.

On every Music asset page, have a small “Royalty Source” box:
“Streaming platforms pay the rights holder. MantleMuse pays investors based on verified royalty statements.”
12) Acceptance Criteria Checklist (Dev-Orchestration Ready)
A user must be able to:
Explore assets with filters


Open detail page and understand returns


Connect wallet and switch to Mantle


Invest with review + confirmation states


See position reflected in portfolio


See payout history / next payout


Sell shares and see proceeds
